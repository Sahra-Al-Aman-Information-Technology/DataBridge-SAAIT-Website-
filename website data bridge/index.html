STEP-BY-STEP WORKFLOW

From Source Connect to Power BI in 6 Automated Steps

Zero complex YAML, zero brittle Python scripts, zero maintenance overhead.

01

Register Source DB

Input connection credentials into the AES-256 Vault. DataBridge tests socket connectivity, connection pooling, and verifies minimal read permissions.

02

Auto-Profile Schema

DataBridge introspects catalogs, foreign keys, partition ranges, primary keys, and data types across Oracle, SQL Server, and relational databases.

03

Configure Load Strategy

Select Full Load, Incremental Delta (High-Watermark timestamp), or Smart Merge Override for collision-free deduplication and upserts.

04

Run High-Speed Ingestion

Multi-threaded PyArrow workers stream records in chunked memory buffers directly to the target staging layer without hitting local disk.

05

Auto DDL Alignment

Target warehouse tables are inspected and non-destructively updated with automatic `ALTER TABLE` DDL executions if upstream schemas changed.

06

Trigger Power BI Refresh

Post-ingestion validation runs automatically, followed by a secure REST/XMLA trigger that refreshes downstream Power BI semantic models.
